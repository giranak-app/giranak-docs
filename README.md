# Giranak Docs

Project documentation for Giranak.

## Structure

- `use-cases/`: use case lists and descriptions
- `prd/`: product requirements document
- `srs/`: software requirements specification
- `screens/`: screens list and UI/UX brief
- `adr/`: architecture decision records

## Rules

- Every decision goes into `adr/` as a numbered file (0001, 0002, ...).
- Changes go through a PR like code.
